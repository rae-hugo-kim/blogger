# 리딩노트 문체 가이드 (원문 어투 존중)

외부 글(아티클, 번역, 커뮤니티 게시물)을 읽고 쓴 노트의 기준입니다. `categories`에 `리딩노트`가 포함된 글에 적용됩니다.
구조·SEO·정제 불변 규칙은 [`tone-guide.md`](tone-guide.md)(공통)를 따릅니다.

## 적용 대상

- aiwitness 번역/아티클을 읽고 쓴 노트
- fmkorea 인기글 등 커뮤니티 글에 대한 단상 모음
- 책/문서/뉴스 등 읽을거리에 대한 감상과 사견

드래프트 작성 시 `drafts/<slug>/index.md` 상단에 미리 기입합니다:

```yaml
---
categories: ["리딩노트"]
---
```

## 문체: 원문 어투 존중

리딩노트의 결은 아직 한 가지로 고정하지 않습니다. 쓰던 어투를 그대로 둡니다.

- 해요체, 개조식(~함/~음/~임), 서술체(~다) 모두 허용
- 한 글 안에서 어투가 전환되는 것도 허용 (개조식 도입 → 서술체 마무리 등)
- 어미 통일/변환 금지 — 해요체로 바꾸지 않음
- "필자" 등 기술 글의 금지 표현도 리딩노트에서는 허용

## 정제 강도: 교정만

에세이와 동일하게 **문체 변환이 아니라 교정**입니다.

- 허용: 오탈자/맞춤법 교정, 문단 간격 정리, 명백한 비문 수정
- 금지: 어미 통일, 문장 순서 재배열, 표현 "개선"/어휘 교체, 단락 요약·확장
- 질문형 섹션 전환(검색 친화 구조)은 적용하지 않음 — 기술 글 전용

## 구조: 출처 우선

- 글 시작에 읽은 대상의 출처를 정리 (원문/번역/커뮤니티 링크)
- 무엇을 읽고 쓴 노트인지 도입에서 알 수 있게 — 링크만 덜렁 두지 않기
- 인용·요약과 사견을 구분 — 원문 내용 인용은 blockquote로
- 여러 글에 대한 단상 모음이면 주제별로 h2 구분

## 프론트매터

- `title`: 읽은 대상/주제 기반 (예: "AI Native 조직 운영기를 읽고")
- `description`: 자유 — 한 줄 사견 허용, 150-160자 강제 없음
- `tags`: 다룬 주제 키워드 (공통 규칙 3-7개)
- `level` 필드는 사용하지 않음
