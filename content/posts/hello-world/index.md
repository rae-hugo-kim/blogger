## Hugo 블로그를 시작하며

안녕하세요! 이 블로그는 [Hugo](https://gohugo.io)와 [Blowfish](https://blowfish.page) 테마로 만들어졌습니다.

Hugo는 Go 언어로 작성된 빠른 정적 사이트 생성기입니다. 마크다운으로 글을 작성하면 HTML로 변환해 줍니다.

## Hugo의 장점

- **빠른 빌드 속도**: 수천 개의 페이지도 수 초 안에 빌드됩니다.
- **간단한 배포**: 정적 파일이므로 GitHub Pages, Netlify 등에 쉽게 배포할 수 있습니다.
- **마크다운 지원**: 익숙한 마크다운 문법으로 글을 작성합니다.

## 간단한 예제

새 포스트를 만들려면 다음 명령어를 사용합니다:

```bash
hugo new posts/my-new-post/index.md
```

로컬에서 서버를 실행하려면:

```bash
hugo server -D
```

`-D` 플래그를 사용하면 드래프트 포스트도 미리 볼 수 있습니다.

## 앞으로의 계획

앞으로 Go, Rust, 클라우드 인프라, 개발 도구 등 다양한 기술 주제로 글을 작성할 예정입니다. 많은 관심 부탁드립니다!
