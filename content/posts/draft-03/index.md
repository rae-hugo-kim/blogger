## 들어가며

오늘은 컨디션 이슈로 정상 업무를 볼 수 없어서, 간만에 Claude Code의 원격 관련 기능들을 써봤어요.

전통적으로는 구글 크롬 원격이나 윈도우 원격 데스크톱을 쓰겠지만, 저는 접속 채널에 구애받지 않고 Claude Code 세션을 그대로 이용할 수 있는 **Remote Control**을 시도해봤습니다.

## Remote Control 세팅

터미널에서 `/rc`를 입력하면 해당 세션이 리모트 컨트롤 가능하게 연결돼요.

![RC 실행](image.png)

그러면 Claude Code 앱(데스크톱이든 모바일이든)에서 접근이 가능해집니다.

![앱에서 접속](image.png)

이 경우 리모트 컨트롤로 작동하는 앱에서의 세션은 별도의 세션이 아니라, **실질적으로 '로컬의 세팅 그대로 터미널을 미러링'하는 형태**로 동작해요. 그래서 로컬에서 사용 중인 하네스, 스킬, MCP, hook 등을 모두 동일하게 쓸 수 있어요.

![커스텀 스킬 작동](image.png)

이런 식으로 데스크톱 앱에서도 직접 만든 커스텀 스킬이 제대로 작동하고, 스킬 콜링 메시지도 잘 보입니다.

## 한계와 아쉬운 점

다만 차이점이라면,

![HUD 미지원](image.png)

- **OMC의 HUD를 이용할 수 없다는 점**
- **슬래시 커맨드를 직접 사용할 수 없다는 점**

![슬래시 커맨드 불가](image.png)

그래서 아주 완벽하게 작업을 대체할 수는 없었어요. 저는 수동으로 `sum`을 하고 `/clear`를 하는 형태로 컨텍스트 관리를 하고 있기 때문에, 오토 컴프레션에 대한 부담이 여전히 남아있거든요.

## 오늘 한 작업: 하네스 분석

![하네스 작업](image.png)

아무튼 그래서 오늘은 하네스 작업을 좀 더 진행했는데요, 다른 분과의 댓글에서 "serena를 의외로 실제로 쓰지 않는 게 아냐?"라는 걸 점검하고 여러 계층으로 분석하고 있어요.

일단 최초의 init 단계에서 자동으로 serena를 띄우지 않는 건 발견했는데, 같은 에이전트에게 추가 정보를 계속 주면서 되물을 때마다 Serena와 OMC LSP, Claude의 LSP 역할 레이어에 대해 말이 자꾸 바뀌고 있어요. 이해하려고 다양한 방식으로 되물으면서 각자의 역할을 알아가고 있습니다.

최종적으로는 Serena도 두는 쪽으로 갈 것 같아요. 툴 콜링 로직이 충분히 괜찮아져서 항상 쓸데없는 MCP를 다 호출하지도 않고, 프로젝트가 커질수록 serena는 확실히 필요해질 테니까요.

## 오늘의 깨달음

모르지만 용감하게 아는 만큼만 말하다 보면, 모르는 것을 어떻게 알아가야 하는지 힌트를 얻게 된다는 걸 느꼈어요. 내가 뭔가를 잘못 알고 말해서 쪽팔린 건 순간이지만, 그래서 그걸 제대로 알고 고치면 그 다음에 더 큰 문제가 생기지는 않겠죠 ㅋㅋㅋ

## 마무리

아무튼 컨디션 이슈로 오늘은 여기까지만 할게요.

RC도 아직 갈 길이 좀 멀고, 아주 완벽하게 원격 작업을 지원한다는 느낌보다는 **"급한 불을 끌 수 있다"** 정도로 느껴지네요. 슬래시 커맨드 관련해서는 이슈가 많이 올라오고 있다고 하니 곧 지원하지 않을까 기대해봅니다.
