## LLM으로 개발하는 일반인의 하루

개발하던 지인들 말로는 지금 제 개발 속도와 수준이 말이 안 된다고 하더라고요. 저도 동의해요. 불과 몇 달 전엔 Claude가 세상에 존재하는지도 몰랐던 평범한 사람이 '개발'을 한다고 말할 수 있다니 신기하죠.

물론 인터넷이 끊기고 LLM 서버가 터지면 여전히 '개발 못 하는 일반인'인 건 똑같지만요...

오늘은 ChatGPT 이용권 마지막 날이라 그쪽 작업을 좀 하느라 실제 작업량은 생각보다 적었어요.

## 부품 목록 정렬 개선

부품 뭉치가 보이는 곳에서 페이지마다 순서가 제각각인 걸 발견했어요. 당연히 예쁘게 순서대로 정렬하는 게 좋겠다 싶어서 수정했습니다.

이제 표처럼 깔끔하게 보이고 부품 종류도 잘 보이네요. 흑흑, 결국 남이 만든 거 참고하는 거구나 싶어요.

> 개인의 디자인은 나빠서 개인의 디자인인 것이다.

외에는 질문 답변 구간에서 부품 재사용 옵션에 VGA가 빠져 있어서 추가했어요.

## GitHub Actions 타임아웃 문제 해결

GitHub Actions가 30분 넘게 도는 문제를 해결하기 위해 Opus님과 대화해봤어요. 결론은 청크로 나눠서 작업해야 한다는 거였죠.

최초에는 오류를 피하려고 한 개씩 한 개씩 검색해서 등록하게 코드를 짰다고 하더라고요. 처음에는 한 번만 불러오면 돼서 잘 됐는데, 데이터를 점점 자세하게 요구하다 보니 시간이 늘어져서 타임아웃이 났대요.

크롤링 데이터 가져오는 쪽을 고쳐서 이제는 잘 작동합니다! 여러분, 다나와 가격 정보는 안전해요!

## 부품 리뷰 기능 추가

제품 리뷰야 구매처마다 다 있는 기능이지만, 제가 원한 건 좀 달랐어요.

디갤러들이 써본 부품, 실제로 구매했던 가격, 날짜, 할인 정보 등을 가지고:
- **실제로 기대할 수 있는 이 부품의 가격**
- **실제로 추천/비추천 하는 사용 경험**

이런 걸 공유하고 아카이빙 하면 의미 있을 거라 생각했거든요. 많은 분들이 수고스럽게 데이터를 쌓아주셔야 할 테니 아주 먼 미래의 일이겠지만요.

## Claude Code의 /btw 명령어

`/btw` 명령어 정말 좋아 보여요. 작업은 작업대로 하면서 Claude에게 궁금한 걸 바로바로 물어볼 수 있거든요.

LLM으로 작업하는 경우 선배 개발자들이 많이 해주시던 조언이 **'개발의 주도권을 잃지 말라'**는 거였어요. 저처럼 배경이 없거나 얕을수록 에이전트가 선택한 기술이나 방식에 의문을 많이 갖게 되는데, 작업 흐름을 끊으면서 물어보기 그러니까 별도 세션에서 따로 정리해서 묻거나 했거든요.

그 와중에 작업은 진행돼서 다음 프로세스를 기다리고... 그랬는데 저렇게 간단한 건 물어보고 해결하면 괜찮은 것 같아요.

실제로 플랜 모드에서 대답할 때 1, 2, 3 바로 선택하기보단 맨 밑으로 내려서 'Claude에게 추가로 뭔가 얘기하기'를 하는 편이에요. 쓸모가 있어 보여요.
