## 오늘 알게 된 신기한 도구: Maestro

동료한테 재미있는 도구를 소개받았어요. [Maestro](https://github.com/mobile-dev-inc/Maestro)라는 모바일 E2E 테스트 프레임워크인데요, 모바일 플레이라이트 같은 느낌이랄까요?

처음엔 "브라우저 콘솔 열고 모바일 모드로 바꾸면 되는 거 아니야?" 싶었는데, 실제로 개발용 서브폰에서 자동으로 테스트가 돌아가는 걸 보니 신기하더라고요. 저도 샤오신패드가 있으니 나중에 한번 시도해볼 생각입니다.

## 오늘의 메인: 싸이월드 미니룸 감성 PC 꾸미기 기능

![개발 화면](image.png)

오늘은 마이페이지에 재미 요소를 넣어봤어요. 싸이월드 미니룸처럼 포인트로 PC 부품을 구매해서 나만의 컴퓨터를 꾸미는 기능이에요.

### 구현 개요

```
부품 구조:
- 메인보드: 전체 티어를 결정, 다른 부품의 기능 해금 제어
- 각 부품: 고유 기능 해금 / 배수 증가 / 쿨타임 감소
- 일부 부품: 꾸미기 아이템, 칭호 보관 관련 기능
```

![부품 목록](image.png)

AI한테 제품명을 패러디해서 넣으라고 했더니 이런 식으로 만들어 놨네요 ㅋㅋㅋ 창의성이 좀...

커뮤니티는 많은 사람들이 즐겁게 머물러야 한다고 생각해서, 황견적이 라이트 버전을 넘어 다음 단계로 나아가는 날을 상상하면서 이것저것 붙여보고 있어요. 이런 경험들이 나중에 진짜 커뮤니티를 개발하거나 유지보수할 때 자산이 되겠죠.

## Claude 프로젝트 스킬 개선

기존에 GitHub에 올렸던 Claude 프로젝트 스킬을 로컬로 가져와서 내용을 손봤어요. 생각해보니 Claude 문서와 폴더 트리는 GitHub에서 받아 쓸 수 있는데, 정작 핵심 스킬은 전역 설정으로만 넣어뒀더라고요. 다른 곳에서 제 템플릿을 받아 쓸 때 스킬을 못 쓰는 문제가 있었죠.

특히 `sum` 스킬을 개선했어요:

**기존**: 현재 세션의 작업 리스트만 체크하고 기록

**개선**: 
- 문제가 왜 발생했는지
- 어떤 방식으로 접근해 해결했는지
- 결과가 어떻게 됐는지

이제 `sum` 명령어로 저장한 문서를 읽는 것만으로도 프로젝트에서 발생했던 개발 과정을 상세히 이해할 수 있을 거예요. 에이전트도 비슷한 실수를 반복하지 않겠죠.

오답 노트를 적는 건 중요하니까요.
